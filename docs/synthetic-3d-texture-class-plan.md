# G13: план проверки классов текстуры земли

Дата фиксации протокола: 2026-10-06. Результаты в этот документ до фиксации
конфигураций не добавляются.

G13 продолжает [G12](synthetic-3d-pose-interactions-report.md), где три новых
seed всё ещё принадлежали одной богатой процедурной текстуре. Термины объяснены
в [тезаурусе](glossary.md).

## Практический вопрос

> Сохраняет ли неизменённый SIFT + RANSAC gate безопасность, когда земля
> перестаёт быть богатой уникальными деталями?

Проверяются два разных провала:

1. гладкая поверхность может не дать достаточного числа локальных признаков;
2. регулярные ряды могут дать много похожих, но неоднозначных признаков.

В первом случае правильный результат — честный отказ. Во втором допустим либо
точный ответ, либо отказ. Уверенный неправильный ответ является провалом.

## Основание метода

Оригинальная статья SIFT объясняет, что полезный локальный дескриптор должен
быть одновременно воспроизводимым и различимым:
[David Lowe, Distinctive Image Features from Scale-Invariant Keypoints](https://www.cs.ubc.ca/~lowe/papers/ijcv04.pdf).

Рабочий baseline проекта использует два ближайших дескриптора и ratio test
Лоу через `BFMatcher.knnMatch`, как в официальном руководстве
[OpenCV Feature Matching](https://docs.opencv.org/4.x/dc/dc3/tutorial_py_matcher.html).
Повторяющийся рисунок должен уменьшать отличие лучшего кандидата от второго и
тем самым провоцировать отказ, но это проверяемая гипотеза, а не гарантия.

RGB-текстура передаётся в штатный буфер `bpy.types.Image.pixels`:
[Blender Python API](https://docs.blender.org/api/4.5/bpy.types.Image.html).
Внешние изображения и новые зависимости не используются.

Конфигурация продуктовой оценки:

- `experiments/configs/synthetic_3d_g13_texture_evaluation.json`;
- SHA-256:
  `14a5e8e24338ac61f4ee74a202ac60dba1771685afbad6253d93b7b297aadd65`.

Три класса:

- `rich_irregular` — прежняя богатая текстура G1--G12; контроль
  отсутствия регрессии;
- `low_detail` — только плавные низкочастотные изменения цвета без
  резких углов;
- `periodic_rows` — одинаковые прямоугольные элементы в регулярных
  рядах с большим числом повторяющихся углов.

Для каждого класса используются три seed: 20261301, 20261302 и 20261303.
Одинаковый seed сохраняет одинаковое размещение 240 камней, пней и кустов.
Меняется только класс текстуры земли.

Четыре Repeat-позы:

- совпадающая камера;
- боковой базис 0,4H;
- боковой базис 0,8H;
- наклон оптической оси 40°.

Итого 3 класса × 3 seed × 4 позы = 36 попыток. Экспозиция, тень, размытие,
разрешение, геометрия, маска и пороги gate не меняются.

## Входы алгоритма

Рабочая ветка получает:

- RGB Teach;
- консервативную Teach-маску земли;
- 12 соответствий «Teach-пиксель ↔ локальные метры карты»;
- RGB Repeat.

Класс текстуры, seed, поза камеры, точные маски и плотные мировые координаты
доступны только оценщику после построения привязки.

## Заранее заданный критерий

Серия проходит только при одновременном выполнении условий:

- 0 ложных принятий абсолютной точки;
- 0 ложных принятий продуктового вектора;
- богатый контроль даёт 12 из 12 корректных межкадровых ответов;
- p95 ошибки каждого принятого вектора не выше 0,25 м;
- 0 ошибок знака ненулевых компонент;
- 0 метрических сбоев;
- минимум 5 независимых пар на каждый направленный вектор.

Для `low_detail` и `periodic_rows` минимальная доступность
намеренно не задаётся. G13 должен сначала локализовать механизм отказа, а не
вынудить алгоритм отвечать там, где доказательств мало.

После просмотра результата критерий и пороги не ослабляются.

## Ограничения

- Это три искусственных класса, а не реальные трава, снег или посевы.
- Текстура не меняется между Teach и Repeat.
- Объекты статичны, а Teach-маска точна.
- Земля плоская.
- Карта, реперы и клики не содержат ошибок.
- Радиальное искажение и rolling shutter остаются следующим отдельным срезом.
