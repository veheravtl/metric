# G14-C2: узкий шумовой срез и единогласное решение

Дата запуска: 2026-10-07. Протокол C2 и следующего G14-D зафиксирован
коммитом `8dfcbc0`, общий агрегатор и модель цепочки — `55066b5`, запускаемый
сценарий —
`1ce7baf`. Все три коммита сделаны до первого запуска C2.

## Короткий вывод

G14-C2 **валиден и формально прошёл безопасность и доступность**:

- 252 физических случая, 1260 компонентных и 252 итоговых решения;
- все 9 номиналов построены, метрически корректны и приняты;
- ни один из 23 ошибочных шумных случаев не принят правилом 5/5;
- принято 88 из 243 шумных случаев, или 36,2%, при заранее заданном минимуме
  10%.

Однако это не означает, что правило 5/5 уже годится для рабочего прототипа.
Все 81 физически правильный кадр с наклоном 40° были отклонены. Общая
доступность прошла критерий в основном благодаря совпадающей позе: там приняты
все 81 из 81 шумных кадров.

## Что проверялось

На прежних трёх богатых плоских текстурах и трёх позах проверены sigma 20,
22,5, 25, 27,5, 30, 32,5, 35, 37,5 и 40. Для каждого уровня созданы три новые
реализации шума. Это дало 27 шумных кадров на уровень.

Каждый результат привязки анализировался пятью независимыми проверками на
случайных подвыборках совпадений; генераторы случайных чисел были заранее
зафиксированы. Итоговое решение разрешалось только при пяти компонентных
принятиях из пяти. Порог разброса 5 px, 30 подвыборок на компонент и доля
подвыборки 80% не менялись.

что именно единогласие исправило старый сбой sigma 30: тот механизм на новых
реализациях не повторился ни для одного отдельного seed.

## Сильная зависимость от позы

| Поза Repeat | Шумных случаев | Верны физически | Приняты 5/5 |
| --- | ---: | ---: | ---: |
| Совпадающая | 81 | 81 | 81 |
| Боковой базис 0,8H | 81 | 58 | 7 |
| Наклон 40° | 81 | 81 | 0 |

Это важнее общей цифры 36,2%. Gate почти бинарно разделил позы и отклонил 132
физически правильных случая. В частности, отказ всех наклонных кадров вызван
не метрической ошибкой: их максимум оставался не выше 0,183 м.

## Пересмотр инженерной рекомендации

Новый факт, изменивший решение: заранее заданная общая доступность пройдена,
но разрез по позам обнаружил 0/81 ответов на полностью корректном наклоне.

Что остаётся верным: пять фиксированных проверок дают воспроизводимое решение
с безопасным отказом — fail-closed; все увиденные опасные шумовые кадры
остановлены, а номинал сохранён полностью.

Что говорит против немедленного принятия 5/5: ни один отдельный компонент в C2
не сделал ложного допуска, поэтому выигрыш единогласия не изолирован; цена
правила сильно зависит от позы и делает одну проверенную позу полностью
неработоспособной.

Итог: C2 считается положительным по заранее заданным критериям, но правило 5/5
пока не переносится в продуктовый контракт. Для сравнения альтернатив
потребуется новая отложенная выборка, сбалансированная по позам, и заранее
заданный критерий доступности отдельно для каждой позы.
