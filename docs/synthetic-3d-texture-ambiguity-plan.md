# G13-R: план проверки неоднозначной Teach-текстуры

Дата фиксации протокола: 2026-10-06. Итог записывается в отдельный отчёт после
коммита и публикации этого плана. Термины проекта объяснены в
[тезаурусе](glossary.md).

## Зачем нужен follow-up

[G13](synthetic-3d-texture-class-report.md) нашёл опасный случай: на
периодических рядах одна гомография выглядела почти идеально, но переносила
точки на неверную копию узора. Ошибка межкадрового вектора достигла 63,1 м,
хотя внутренний gate принял результат.

Обычные проверки отвечали на вопрос: «насколько хорошо одна найденная модель
объясняет выбранные соответствия?». G13-R добавляет другой вопрос:

> Есть ли у большого числа локальных признаков почти одинаковые копии далеко в
> том же Teach-кадре?

Если да, система не пытается угадать правильную фазу рисунка и заранее
отказывается от измерения.

## Основание метода

SIFT описывает небольшую окрестность ключевой точки вектором из 128 чисел.
Евклидово расстояние между такими векторами служит мерой различия. Оригинальная
работа подчёркивает важность различимости локальных признаков:
[David Lowe, Distinctive Image Features from Scale-Invariant Keypoints](https://www.cs.ubc.ca/~lowe/papers/ijcv04.pdf).
Практика сопоставления ближайших дескрипторов сверена с
[официальным руководством OpenCV](https://docs.opencv.org/4.x/dc/dc3/tutorial_py_matcher.html).

G13-R не заменяет SIFT или RANSAC собственной привязкой. Это узкий
предварительный guard над теми же SIFT-признаками. Для каждого Teach-признака
он ищет наиболее похожий признак не ближе 64 пикселей. Ближние точки исключены,
чтобы несколько масштабов или ориентаций одного физического угла не считались
копиями местности.

## Как выбран порог

Порог является результатом разработки на известных девяти Teach-кадрах G13,
а не независимым доказательством:

| Класс | SIFT-признаки | Доля удалённых копий |
| --- | ---: | ---: |
| богатая нерегулярная, 3 seed | 1027–1067 | 0,027–0,042 |
| низкодетальная, 3 seed | 12–27 | 0,000 |
| периодические ряды, 3 seed | 678–693 | 0,524–0,541 |

Удалённой копией считается дескриптор с расстоянием не больше 80. Guard
срабатывает, если найдено хотя бы 200 признаков и доля копий выше 0,20. Между
наблюдаемыми классами оставлен широкий зазор; точное значение 0,20 пока не
выдаётся за универсальный полевой порог.

Низкодетальная поверхность не объявляется периодической: у неё просто мало
признаков, и это уже обязан безопасно обработать основной gate.

## Замороженная независимая проверка

Конфигурация:

- `experiments/configs/synthetic_3d_g13r_ambiguity.json`;
- SHA-256: `86de24ca16d3388197ab16f0115cf8beb19f66bfbb1dcb16cd86e6f443487d1e`.

Проверяются девять новых Teach-сцен с seed 20261321–20261323: по три богатых,
низкодетальных и периодических. Размещение 240 объектов согласовано между
классами одинакового seed. Рендерится только одна Teach-камера; Repeat для
проверки свойства самого опорного кадра не нужен.

Рабочие входы guard:

- RGB Teach;
- консервативная Teach-маска земли после той же эрозии, что использует matcher.

Класс текстуры, seed, скрытая геометрия Blender и результаты G13 доступны
только оценщику после решения.

## Заранее заданный критерий

Серия проходит только при одновременном выполнении условий:

- все 3 новых периодических Teach-кадра отклонены как неоднозначные;
- ни один из 3 новых богатых кадров не отклонён;
- ни один из 3 новых низкодетальных кадров не назван периодическим;
- при ретроспективном применении к G13 исчезает известное ложное принятие;
- богатый контроль G13 сохраняет 12 из 12 корректных принятий.

Последние два пункта являются проверкой исправления и отсутствия регрессии на
старой development-серии. Первые три — проверка зафиксированного правила на
новых seed.

## Ограничения

- Три новых seed одного генератора не заменяют разные реальные типы поля.
- Guard видит повторяемость только внутри кадра. Одинаковый участок за его
  границей останется неизвестным.
- Отказ безопасен, но уменьшает доступность: правильная фаза не выбирается.
- Поза, высота и освещение Teach пока фиксированы.
- Это проверка наблюдаемого сигнала, а не готовый универсальный классификатор
  текстур.
