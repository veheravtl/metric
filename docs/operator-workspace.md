# Операторская панель и файл рабочего проекта

Смежные термины собраны в [тезаурусе проекта](glossary.md).

## Задача и выбранный подход

Длительная покадровая привязка не должна зависеть от одного непрерывного
запуска. Поэтому ежедневные команды собраны в перемещаемой панели, а разметка
сохраняется как версионированный JSON-проект.

Панель реализована как закрепляемое окно Qt — QDockWidget. При первом запуске
она плавает поверх главного окна; оператор может пристыковать её к краю.
Кнопки панели вызывают те же действия, что и меню, поэтому второй независимой
копии состояния нет.

Закрытую панель можно вернуть через «Вид → Операторская панель» или сочетанием
Ctrl+Shift+O. При запуске приложение принудительно показывает основной рабочий
инструмент. Если сохранённые координаты относятся к уже отключённому монитору,
панель автоматически пристыковывается к правому краю главного окна.

Первичные источники решения:

- [QDockWidget](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QDockWidget.html)
  описывает плавающий и закрепляемый режимы;
- [QMainWindow](https://doc.qt.io/qtforpython-6/PySide6/QtWidgets/QMainWindow.html)
  предоставляет saveState и restoreState для расположения панелей;
- [os.replace](https://docs.python.org/3/library/os.html#os.replace) заменяет
  старый файл новым атомарно в пределах одной файловой системы;
- [tempfile](https://docs.python.org/3/library/tempfile.html) создаёт соседний
  временный файл перед заменой.

## Команды панели

Панель позволяет открыть и сохранить проект, ввести видимый номер кадра,
вернуться к месту остановки, найти следующий проблемный кадр, показать оверлей,
управлять сопровождением, войти в коррекцию и выбрать маяк по постоянному
номеру.

Операторская нумерация начинается с единицы: кадр 1 соответствует внутреннему
индексу 0. Одиночный клик по кадру до клика по карте является временной точкой.
Кнопка отмены или Esc удаляет только её. Сохранение незавершённой пары
блокируется с понятным объяснением.

## Содержимое и безопасность проекта

Файл с суффиксом .aerial-project.json хранит версию схемы, пути и контрольные
признаки исходных материалов, последний кадр, постоянные номера маяков,
покадровые наблюдения, гомографии, машинные опоры, признаки качества и состояния
keyframe, tracked, draft, rejected, excluded и stale.

Видео и карта внутрь JSON не копируются. Для большого файла сохраняются размер
и хеш крайних блоков, для каталога пролёта — хеш метаданных и крайних
изображений. Это обнаруживает обычную подмену без чтения гигабайт, но не
является полным хешем каждого байта.

Запись идёт во временный файл в том же каталоге, сбрасывается на диск и заменяет
прежний JSON через os.replace. После первого ручного сохранения изменения
автоматически записываются после короткой паузы. При несохранённой работе
настоящий запуск приложения предлагает сохранить, закрыть без сохранения или
отменить закрытие.

## Коррекция прошлого

Команда «Исправить этот кадр» останавливает сопровождение и разблокирует маяки.
Фактическая правка переводит кадр в черновик. Прошлые кадры не меняются, а
зависимые машинные результаты будущего получают состояние stale только до
следующего вручную подтверждённого keyframe. Их старая гомография удаляется,
поэтому её нельзя случайно использовать для измерения.

## Ограничения первого варианта

- выборочный контрольный признак не равен полному SHA-256 большого видео;
- автосохранение начинается только после выбора имени проекта;
- временная одиночная точка не сохраняется;
- пути пока абсолютные, переносимый архив материалов не реализован;
- stale-кадры не пересчитываются в фоне: оператор явно продолжает трек.
