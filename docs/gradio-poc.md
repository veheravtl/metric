# Локальный интерфейс Gradio для PoC

## Зачем в проекте появился GUI

На этапе проверки реализуемости недостаточно сохранять только числа и матрицы.
Ошибочная гомография иногда имеет правдоподобную среднюю метрику, но визуально
сразу выдаёт себя двойными контурами, смещением перекрёстка или совпадением
только в одной части кадра. Поэтому интерфейс используется как диагностический
инструмент рядом с автоматическими тестами, а не вместо них.

## Что такое Gradio

Gradio — Python-библиотека для построения локальных веб-интерфейсов вокруг
функций обработки данных и моделей машинного обучения. Программа запускает
локальный HTTP-сервер, а пользователь работает с ним через обычный браузер.
Для текущего запуска используется адрес 127.0.0.1, публичная ссылка отключена,
поэтому эталонное изображение не отправляется во внешний сервис.

Основные понятия:

- Blocks описывает компоновку страницы;
- Image, JSON, Button, Slider и другие компоненты отображают данные;
- события click, change и select связывают действия пользователя с функциями
  Python;
- State позволяет хранить состояние отдельной пользовательской сессии;
- Queue управляет последовательностью длительных вычислений.

Gradio не является математическим ядром проекта. Обработчики интерфейса только
вызывают функции из пакета aerial_mapper и отображают возвращённые NumPy-массивы
и словари. Благодаря этому те же функции можно использовать в тестах, пакетной
обработке или будущем Qt-приложении.

## Запуск

Сначала должен существовать локальный эталон:

    uv run python scripts/download_reference.py

Затем запускается интерфейс:

    uv run python apps/poc_web.py

Страница откроется по адресу http://127.0.0.1:7860.

## Что показывает первая версия

1. Полный эталонный GeoTIFF с оранжевым следом виртуальной камеры.
2. Синтетический прямоугольный кадр размером 1280 на 960 пикселей.
3. Обратное наложение кадра на эталон.
4. Истинные матрицы гомографии, координаты углов и параметры опыта.

В обратном наложении красный канал представляет синтетический кадр, а зелёный
и синий — эталон. Точное совпадение выглядит серым. Ошибка создаёт красные и
бирюзовые двойные контуры.

## Что Gradio позволит добавить дальше

- слайдеры наклона, поворота, размытия и силы дисторсии;
- щелчки по изображениям для ручного задания пар соответствующих точек;
- загрузку кадров и видео пользователя;
- таблицу координат и результатов измерений;
- графики ошибки и доли успешных кадров;
- галерею удачных и неудачных экспериментов;
- потоковое отображение кадров;
- сохранение артефактов и параметров запуска;
- простую парольную защиту локального сервера при необходимости.

Gradio подходит для экспериментов и демонстрации модели, но не гарантирует, что
останется финальным интерфейсом. Qt стоит рассматривать позднее, если появятся
требования к сложному редактору разметки, высокой частоте показа видео,
настольной упаковке или глубокой интеграции с операционной системой.
