# Данные проекта

Каталоги `reference/` и `queries/` предназначены соответственно для эталонных
карт и входных кадров. Их содержимое по умолчанию исключено из Git, поскольку
аэрофотоснимки могут быть большими, иметь лицензионные ограничения или содержать
чувствительные координаты.

Небольшой демонстрационный файл можно добавить в репозиторий только после
проверки лицензии. Рядом с ним необходимо указать источник, автора, лицензию и
дату получения.

## Временный эталон для feasibility spike

Для проверки геометрического конвейера выбран квадрат ортофотоплана Черкасс
2021 года. Это только PoC-источник: в полевом эксперименте он будет заменён
собственным снимком полигона и контрольными точками в локальной метрической
системе координат.

Параметры источника и выбранной области хранятся в файле
manifests/cherkasy_2021_poc.json. Локальный GeoTIFF воспроизводится командой
uv run python scripts/download_reference.py.

Результат сохраняется в reference/cherkasy_2021_poc.tif. Каталог reference
исключён из Git: официальный сервис доступен публично, однако условия повторного
распространения самого изображения требуют отдельной проверки. Вместе с растром
создаётся локальный JSON с фактическими границами, датой загрузки и контрольными
суммами.

GeoTIFF записывается в EPSG:32636 (WGS 84 / UTM zone 36N), поэтому его
координаты выражены в метрах. В основной логике абсолютные UTM-координаты не
должны быть обязательными: будущий полигон сможет использовать произвольную
локальную систему X, Y, заданную контрольными точками.
